# MaterialIQ

Screen metals for a part in under a minute, with every number traced to its source page.

**Use it:** https://sharanankathi.github.io/materialiq-app/

- Enter your limits (strength, stiffness, density, elongation...) and what you want to optimize.
- Get ranked candidates, what needs more data, and what failed and why.
- Every value links to its page in MIL-HDBK-5J (US Government, approved for public release).
- Nothing is estimated. Missing data is shown as missing.

Current coverage: 14 aluminum, steel, stainless and titanium grades, room-temperature properties.

**Advisory only.** A screening aid, not a material approval, design allowable or certification. Verify every value before use in a design.

Runs entirely in your browser. Nothing you type is sent anywhere.
